# PocketSaver 💰

A monthly income and expense tracker built for college students.

## Live Demo
👉 https://rahultharun5-ship-it.github.io/pocketsaver/

## Features
- Add income and expense entries
- Filter by category
- See balance and savings rate
- Spending breakdown with chart
- Data saved in browser — no login needed

## Built With
- HTML, CSS, JavaScript
- Chart.js
- localStorage API
